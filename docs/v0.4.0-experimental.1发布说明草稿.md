# v0.4.0-experimental.1 — DeepSeek Manual Learning Handoff

**Release说明草稿，尚未发布。建议类型：Pre-release。** 不修改或替换v0.1.3 Stable及v0.3.0-experimental.1历史版本。

## 本版本新增

- 可复制到DeepSeek普通对话的教学指令，沿用目标诊断、教学、练习、错因反馈和相关题复测规则。
- 只读学习记录导出：Markdown接续记录与原始JSON副本，包含目标、知识点、证据、帮助程度、未完成问题、下一步、复习信息与修订号。
- 手动接续指南：导出、粘贴、确认恢复、继续学习、取得返回摘要，再回原环境核对并授权保存。
- 未作答边界明确：仅请求解释或时间、提示后未答、未完成追问，不算提示后完成，不产生新知识证据或改变验证状态。

V0.3数据结构、错因诊断、存储恢复和复习判断逻辑保持不变。没有自动导入、同步或DeepSeek API接入。

## 验证情况

- 初次开发：17/17导出自动测试、35/35原有连续性回归、7/7文件检查与官方Skill格式验证通过。
- 用户实际反馈：统计学学习从当前Skill环境导出后，在DeepSeek新会话恢复主题、知识点、已验证/未验证内容和停留位置；完成迁移练习并生成返回摘要。
- 本次观察未出现虚构旧聊天记忆、历史或保存成功；没有把单题正确升级为完全掌握，也没有将未知时间间隔当作延迟复测。
- 用户报告原第一次练习仍为“判断正确、理由补充后验证”，迁移练习作为新增证据保留。这是返回摘要的用户核对结果，尚非开发代理对本地主文件的独立检查。

## 已发现问题与限制

本次摘要错误地把“用户请求解释时间”的未完成追问标为“提示后完成”。已补充指令与核对规则，但修正后的真实行为尚待复测，不能标为行为修复通过。

返回后本地授权保存与新会话再恢复尚未验证；原定数学折扣、Python列表案例仍待执行。统计学单次反馈不代表全部题目或环境兼容，也不证明学习效果提升。

**DeepSeek目前仅为手动接续验证。** 普通对话无自动本地文件读写能力，返回摘要尚未保存；是否真正写入以原环境工具成功结果为准。没有自动模型接入、实时共享或云同步。

## 使用

先在原环境保存V0.3记录，明确指定源文件与新仓库外导出目录，运行只读导出工具。将教学指令和Markdown记录粘贴到DeepSeek新对话，核对恢复摘要后继续。带回必要返回片段，由原环境重新读取主记录、核对题目/实际作答/帮助程度/时间，并等待明确授权后保存。

见 [DeepSeek指南](DeepSeek使用指南.md)、[当前限制](V0.4限制说明.md) 及 [验收记录](../tests/V0.4最小接续验收.md)。对话无需新增API客户端；导出使用Python 3.10+标准库。个人记录不要上传公开仓库。
