# V0.6：从课程与教材开始

本入口包含在v0.6.3-experimental.1个人实验版本中。增加课程向导、教材登记和章节管理；主动提供文件后可生成目录草稿，确认才写入，详见 [教材导入指南](教材导入指南.md)。不自动寻找教材、下载文件、理解整书或制定全年计划。

## 1. 先说想学什么

在已经打开私人学习库的本地AI环境中发送：

> 我要学习统计学，目标是期末考试，请帮我建立课程。

如果已有统计学课程，应先让你选择沿用，不能默默创建重复课程。它会补问教材、考试日期、当前基础、希望达到的程度。没有教材或日期也可以直接说没有；不了解基础就说不知道。

核对它准备保存的内容，明确确认后建立课程。第一次进入新聊天仍需要私人学习库项目或学习入口文件，不能让AI搜索整个电脑。DeepSeek普通对话仍按原来的手动接续，不会自动访问本地学习库。

## 2. 登记教材，有没有文件都可以

可以提供：教材名称、作者、出版信息、ISBN、版本、来源说明、当前章节。作者不清楚就说未提供；可选信息不应猜测。

例如，仅作为填写方式：

> 登记教材：名称【实际书名】，作者【作者或未提供】，来源【本人纸书/老师提供/其他实际来源】，当前章节【章节名称】。目前没有PDF，请先登记。

有文件时提供你明确选择的完整位置，或主动上传平台支持的附件。仅登记模式记录可访问的PDF、PPT/PPTX、TXT文件名、版本和修改时间；上传附件若没有可访问路径，应说明无法核对，先登记暂无文件，不能声称已经导入或理解。

仅登记不读内容；主动要求导入时可本地提取目录草稿，确认后建章。文件不复制进学习库，不改原教材。版本由你填写；教材移动或更新后，可以明确要求更新同一条登记，不自动扫描。第三方网站或仓库仅作为你填写的来源，不自动下载，也不据此宣称版权已验证。请只提供你有权使用的材料。

## 3. 建立章节和知识点

> 给统计学建立“第一章 总体与样本”。知识点先列“总体、样本、抽样方法”，逐个确认后加入。

这里只建立你确认的目录，不表示已经学过，也不从书名自动猜章节。没有整理好的目录也可以先确定一个小章和知识点，之后逐步补充。

## 4. 开始本节学习

> 从“总体”开始。请按我的目标和基础讲解，再出一道练习，等我回答。

要严格按教材学习，请提供本章的小段内容或明确授权读取指定内容。登记书名和路径，不代表AI已经读过教材。学习、作答、错因反馈、保存授权和复习仍按原流程进行。

## 5. 下次继续

关闭聊天后，在同一个私人学习库项目新建聊天，发送：

> 继续学习。

核对课程、章节、上次知识点、未完成问题、验证状态和下一步，再确认继续。未答题必须保持未完成；教材信息不能被当作学习证据。目录补充读取有问题时应单独告知，不能编造教材内容或学习历史。

教材信息的“更新时间”不是作答时间。真实24小时延迟仍按原作答记录判断，不因隔天打开或修改教材就宣布复测通过。

## 6. 这次还需要你验收

请真实完成：统计学课程 → 登记自己的教材 → 建第一章 → 学一个知识点 → 授权保存 → 关闭聊天 → 第二天恢复。检查课程、教材与学习证据是否都在，观察记录见 [V0.6个人验收](../tests/V0.6教材课程入口验收.md)。目前没有你的教材名称/位置和新一轮实际学习结果，开发不会代填或假装完成。
