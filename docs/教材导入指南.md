# 用自己的教材建立课程

本能力包含在v0.6.3-experimental.1实验版本中。只读取你主动指定的文件，不搜索互联网、不下载教材、不自动上传，也不替你判断版权。

## 第一次怎么做

1. 在能读取本地文件的AI环境中打开你选择的私人学习库项目。普通在线聊天不能自动读取电脑；DeepSeek继续使用原来的手动接续方式。
2. 上传你选择的教材附件，或给出这一本教材的完整文件位置。平台若无法提供可读附件位置，AI应说明无法读取，你可以改为粘贴目录文字。
3. 发送下面的话，并把方括号替换为真实内容：

> 我要用这本教材建立【统计学】课程，目标是【理解课程并准备期末考试】。教材文件是【指定文件位置或刚上传的附件】，来源是【你的实际来源说明】。请先提取目录，给我教材信息和章节草稿，我确认后再写入学习库。

4. 新课程会补问教材、考试日期、基础和期望程度。已有统计学课程时先选择沿用，避免重复。未知作者、出版信息、ISBN等可以留空。
5. 检查章节草稿：顺序对吗，有无遗漏，正文是否被误识别成标题？可以要求删改。此时尚未写入章节，也没有任何“已掌握”记录。
6. 确认后回复：“确认将这些章节和教材登记写入这门课程。”只有工具成功，AI才能说导入完成；部分失败应明确指出并帮助核对。
7. 选择一章和一个知识点开始，例如：“从第一章总体与样本开始，先确认我的基础，再讲解和出题，等我回答。”要按教材讲解，可以提供这一节片段，或明确允许读取指定页/范围；提取目录不代表已理解整本教材。
8. 结束时授权保存进度。第二天在同一私人学习库新建聊天，发送：“继续学习。”核对恢复摘要，确认后继续未答题或选择复习。

## 支持和限制

| 文件 | 当前处理 |
| --- | --- |
| PDF | 优先书签；没有书签时从前40页文字寻找标题，需人工核对 |
| PPTX | 目录页或幻灯片标题生成候选，需人工核对 |
| 旧PPT | 可以登记；目录提取请先用演示软件另存为PPTX，保留原文件 |
| TXT | 识别常见章标题、编号或Markdown标题 |
| 扫描/加密PDF | 无OCR、不解密；请提供可读版本或手动目录 |

PDF工具需要运行环境安装pypdf。当前开发环境已有该库；换电脑后不一定有，可让AI先检查，不会自动安装或调用付费服务。其他格式的目录提取无需额外依赖。

原教材不会被自动复制或永久托管：记录保存的是位置和关联。教材移动后需你指定新位置、重新预览并确认。请自己保留原文件及备份。

目录草稿和课程记录属于私人数据，请放在代码仓库外，不把完整教材、真实学习记录或私人路径提交到GitHub。程序不会将文件发送给其他AI；你主动上传附件的平台有其自身的数据处理方式。

目前通过的是虚构文件的自动检查。还需要你提供一本真实教材，完成建课、一次学习和次日恢复，才能确认是否满足你的实际使用需求。填写 [个人验收记录](../tests/V0.6教材课程入口验收.md) 的私人副本即可，不必公开教材或聊天。
