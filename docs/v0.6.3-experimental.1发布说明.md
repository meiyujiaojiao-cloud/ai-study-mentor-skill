# v0.6.3-experimental.1 — Personal Learning & Optional Notes

发布类型：Pre-release / Experimental。MIT，Copyright (c) 2026 AI Study Mentor。Stable v0.1.3及历史v0.3标签保持不变；本版本从实验分支发布，main暂不合并。

## 本次包含

- 保留目标诊断、讲解、练习、错因反馈、授权保存、跨会话恢复、不同相关题复习及真实学习证据规则。
- 个人课程/章节/知识点目录、教材登记和继续学习入口。
- 用户主动提供PDF/PPTX/TXT后的本地目录草稿，确认后写入课程；不自动搜索、下载或上传教材，不判断版权。
- 概念理解、专业表达、应用、迁移分别观察，真实证据随现有摘要保留；表达缺漏可以待验证，后续关联任务检查，不无限同义纠错。
- 可选的本次学习笔记，区分教材、用户表达、实际证据与AI建议。独立文件经授权保存，每次新增、不覆盖旧笔记，不改变学习状态。删除笔记不删证据。
- 保留DeepSeek手动接续与只读导出，不是API接入、自动同步或自动导入。

## 普通用户路线

教材导入 → 确认目录及目标/要求/时间 → 学习并实际回答 → 完成阶段 → 可选复习笔记 → 单独授权保存学习进度 → 新会话核对摘要后恢复。

下载本Release的源码或安装压缩包，保持完整ai-study-mentor-skill目录，按所用Agent安装规则加载。main仍是旧版本，请按本Release下载。完整本地流程需要支持文件及Python的Agent；Codex是已验证环境示例，不是唯一环境要求。详见 [普通学生指南](普通学生使用指南.md) 与 [README](../README.md)。

## 验证

167项自动检查通过，包括笔记新增/旧文件保护/删除与证据隔离、分项摘要兼容、原存储/课程/导入/导出回归和公开文件扫描。官方Skill格式验证通过。具体范围见 [V0.6.3验收](../tests/V0.6.3学习笔记验收.md)。

这些是规则静态与文件操作验证，使用虚构夹具，不是新功能的真人教学成功或学习效果证据。历史中文/英文教学和模型模拟记录按各自报告范围保留，不能当本次笔记与四维评估的真人验收。

## 实验限制

- 未完成大规模真人测试；新笔记质量、分项评估准确性、题目质量和真实教材跨日流程仍需真实使用验证。尚未证明学习效果提升。
- 分项观察及笔记由Agent生成和核对；保存工具不做语义评分、不证明用户理解。
- PDF需pypdf；优先书签，无书签仅检查前40页文字。不支持OCR/解密，旧PPT需用户另存为PPTX。目录提取不等于整本教材理解。
- 其他Agent尚未完整验证。普通在线DeepSeek不能自动访问本地学习库，其独立教学指令没有自动获得后续评估/笔记功能。
- 笔记文件与恢复记录是两种独立输出；笔记保存不能冒称学习进度保存。建议私人数据保存在仓库外。
- 没有数据库、云同步、学习画像、自动提醒、多用户或网站功能。发布不包含私人课程资料、教材原件、真实学习数据、API Key、日志、备份或临时文件。

## English summary

Experimental pre-release with explicitly confirmed material-outline import, multidimensional evidence observations and optional session-based learning notes. Notes distinguish materials, learner wording, actual evidence and AI suggestions; authorized saving creates separate files without modifying learning state. Existing diagnosis, persistence, recovery, review and manual DeepSeek handoff remain unchanged.

167 automated checks and the official Skill validator passed. Large-scale real-user testing is incomplete, note quality and new assessment behavior require real use, and learning improvement is not established. Local file/Python tools are required for the full flow; other Agents are not fully validated. No personal data or textbook files are bundled. Stable tags remain unchanged.
