# AI Study Mentor 普通学生使用指南

**AI Study Mentor 是一个围绕你的学习目标，通过讲解、练习、错误反馈和复习帮助你检查理解的实验性 AI 学习助手。**

本指南已补充 V0.4.1 首次体验入口，沿用 V0.4 实验开发版的手动方式：你复制教学指令和学习记录给 DeepSeek，学习结束后自己保存摘要。没有自动接入、自动同步或自动保存，也不保证提高成绩。

## v0.6.5个人稳定使用流程

本地流程需要你使用的AI环境能够读取指定文件、执行Python并加载完整教学规则。安装时下载 [v0.6.5稳定版本](https://github.com/meiyujiaojiao-cloud/ai-study-mentor-skill/releases/tag/v0.6.5)，具体操作见 [README安装说明](../README.md#安装与开始)。如果当前环境只有在线聊天，请继续使用下方DeepSeek手动流程，不会自动读写电脑。

1. **教材导入**：主动提供一本PDF/PPTX/TXT文件或它的完整位置，说“我要学习统计学，请先提取目录，等我确认后建课”。检查章目录后确认；没有可读目录时可手动提供，不能假装识别整本书。
2. **学习**：告诉AI目标、课程要求和可用时间，选一章一个知识点。听讲后做一道练习，写出答案和理由。专业表达与理解分别看，缺漏可以留待后续关联题检查。
3. **完成阶段**：说“今天先到这里”。你可以选择生成复习笔记、继续学习或暂不生成，不要求全部答对才结束。
4. **生成复习笔记（可选）**：核对其中教材、本人表达、实际题目/回答和AI建议没有混淆；未验证仍应保留。要文件时确认私人保存位置，每次新增一份，不覆盖历史。详情见 [笔记指南](V0.6.3学习笔记使用指南.md)。
5. **保存学习进度**：笔记文件不是恢复记录。要下次继续，另行明确要求保存学习进度，核对位置和内容后确认；只有工具成功才算保存。两种保存不能混称。
6. **下次恢复**：在同一私人学习库项目新建聊天，发送“继续学习”。若AI没有位置，提供原记录位置。核对课程、章节、未完成题和待验证点，确认后继续或复习；不要只提供笔记就认为已恢复状态。

这是个人Stable版本定位，不代表效果验证，不保证提高成绩；尚未完成大规模真人测试，笔记质量需要你实际核对。没有自动上传/下载、账号同步、提醒或全书整理。

## 先试5分钟

打开 [教学指令](DeepSeek教学指令.md)，复制正文全文 → 粘贴到 DeepSeek 新对话并发送 → 再发送“我想学习XXX，请带我开始。”（把XXX换成自己的主题）→ 回答它的目标和基础问题。

教学指令告诉AI按什么步骤陪你学，不是教材或你以前的学习记录。5分钟只用来试着开始，不要求完成全部练习、保存和恢复；不需要答对，也可以停止。完整步骤见第3—6节，遇到问题可看 [FAQ](常见问题FAQ.md)。

## 1. 适合哪些学生

- 想把大学课程中的一个概念弄清楚，而不只是拿到答案。
- 自学数学、统计学或编程，愿意尝试小练习并解释理由。
- 希望保留自己卡住的地方，下次能继续学。

可以先从一个小知识点开始，例如“区分总体和样本”。不同课程的表现还需要继续验证；重要结论请与教材、老师讲解或可靠答案核对。

## 2. 使用前准备什么

1. 一个能够正常聊天的 DeepSeek 账号，打开你平时使用的网页或应用即可。本指南不要求额外购买服务。
2. 一个学习目标，或者一小段你愿意提供的教材、课程笔记或题目。没有材料也可以先说目标，不必上传整本教材。
3. 一个你能找回的笔记位置，例如手机备忘录或电脑文档，用来手动保存学习摘要。

只发送你愿意交给该服务的内容，不包含姓名、学号、账号密码或其他隐私。发送的内容并非只保存在你自己的设备上。

## 3. 第一次使用：复制、粘贴、说目标

### 第一步：复制教学指令

打开 [DeepSeek 教学指令](DeepSeek教学指令.md)，复制正文全文。如果你收到的是转发文件，请让分享者同时发给你这份教学指令。

### 第二步：粘贴给 DeepSeek

打开 DeepSeek，点击“新建对话”或界面中对应的新对话按钮。将教学指令粘贴到输入框，点击发送。不同网页或应用的按钮位置可能不同。

### 第三步：输入学习目标

另发一条消息，可以直接复制：

> 我想学统计学中的“总体和样本”，希望能用生活例子区分它们。我是初学者。请先确认我的目标和基础，再一次教一个小知识点。出题后等我回答，不要直接给答案。

把主题换成你今天要学的内容。如果已经有学习记录，请使用后面的“下次继续学习”步骤。

## 4. 如何开始第一节学习

回答它询问的目标和基础。不知道就说“不清楚”或“没学过”，不用为了通过练习假装懂了。

它应先简短讲解、给一个例子，再出一道练习。你回答时尽量写出理由；答错后，它应指出具体偏差，提供有针对性的解释，并用一道不同但相关的题再检查。

你可以随时发送：

- “完全听不懂，请换更简单的例子，一次只讲一步。”
- “给我一个小提示，先不要给答案。”
- “这题先跳过，请保持未验证。”
- “今天先到这里，请帮我整理学习摘要。”

如果它一次讲太多或代替你回答，就说：“请停在一道题，等我实际回答。”读过讲解或答对一道题，都不意味着整个主题已经掌握。

## 5. 如何保存学习记录

**这里的保存，是你自己把摘要复制到笔记中。AI 生成摘要并不等于它已替你保存。** 这份文字笔记不会自动更新任何其他学习记录。

结束时发送：

> 请整理一份下次可以继续使用的学习摘要，包含目标、当前知识点、本次实际题目、我的回答和理由、是否使用提示、目前已验证与未验证的内容、未完成问题和下一步建议。区分独立回答、提示后回答和已展示答案后的回答。没有实际作答的追问不能写成完成；不要编造时间或历史，也不要声称已经保存。

检查它有没有写错：

1. 题目和你的回答是否真实、完整；代码题是否保留必要代码。
2. 请求过提示的回答，是否如实写成提示后回答。
3. 仅请求解释、询问时间或尚未回答的追问，是否仍为未完成、无新增知识证据、验证状态不变。
4. 以前真实完成的练习是否保留，没有被新摘要覆盖或改成更强的结论。
5. 没有核实的时间是否留为待核对，而不是猜测。

发现错误可以说：“这条我没有回答，请改成未完成，不产生知识证据，也不改变验证状态。”确认后复制到你自己的备忘录或文档，写一个容易找到的标题，例如“统计学学习记录”。自己记录实际学习日期和时间，不确定就留空。

再次打开笔记，确认内容确实保存成功。建议按日期追加每次摘要，保留旧内容，不仅留下AI改写的最新总结。若你原本有其他环境导出的记录，这份笔记只是待核对的补充，不能直接覆盖原文件。

## 6. 如何下次继续学习

1. 打开新的 DeepSeek 对话，再次粘贴教学指令。
2. 打开自己保存的笔记，粘贴相关学习摘要；若有原始导出记录，也一起提供，区分旧记录与新补充。
3. 发送：

> 请只根据我提供的记录，简短说明上次目标、当前知识点、已验证与未验证内容、未完成问题和下一步。先等我确认，不要声称记得旧聊天，不要给未答题答案。

4. 摘要正确后，选择“继续未完成问题”或“先复习，请换一道不同但相关的题，不给答案”。
5. 学习结束后，检查新的摘要并手动追加到自己的笔记。

只说“继续上次学习”而不提供记录，新对话可能不知道你之前学了什么。不要只粘贴电脑文件路径；应粘贴实际内容，或在界面支持附件时上传并核对读取结果。内容太长或没有完整读到时，先停下来确认，不让它猜缺失历史。

下一天可以复习，但只有距最近实际作答至少24小时，才满足当前实验规则中的延迟复测间隔。时间不确定时可以正常复习，不标为延迟通过。

## 7. 目前验证到哪里

已有一次统计学手动使用反馈：能根据记录恢复学习、完成迁移练习并生成返回摘要。也发现过“未回答的追问被误记为提示后完成”的问题，已补充指令，但修正后的行为仍待实际复测。

本指南中的“只在 DeepSeek 学习、手动保存在个人笔记”的完整操作流程尚未单独验收。摘要、答案和恢复结果需要你检查；没有证明学习效果提升，也没有自动保存或跨应用同步。可以先试一个小知识点，再决定是否继续使用。
