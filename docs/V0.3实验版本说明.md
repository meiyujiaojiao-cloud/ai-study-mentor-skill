# v0.3.0-experimental.1 — Minimal Learning Continuity

发布类型：Pre-release。面向 AI 开发者、Agent 使用者与 AI 学习助手构建者的实验版本。v0.1.3 继续作为 Stable，不修改其标签或 Release。

## 新增能力（相对 v0.1.3）

- 错因诊断：根据作答与理由选择针对性解释；证据不足先提问，随反馈更新判断。
- 学习状态保存：用户知情授权后，保存必要摘要到用户选择的仓库外本地文件。
- 跨会话恢复：读取明确指定的记录，展示摘要并等待确认，保留未完成问题。
- 延迟复测：可选的新相关题，至少距最近实际作答24小时才记为延迟；提示后正确不算独立通过。
- 学习证据记录：保留历史证据，区分独立、提示后与讲解后回答；跳过不添加虚构证据。

## 验证情况

- 35项存储、恢复、复习自动测试通过；7项文件检查与官方 Skill 格式验证通过。
- 数学与 Python 模型模拟案例通过，覆盖保存、独立会话恢复及不同题复测；模拟延迟测试使用明确标注的测试时钟。
- 英文保存、独立恢复、同日复习和英转中状态保持通过；中文 A–E 回归通过。
- 全新只读 CLI 会话可原生发现已安装的 V0.3，读取实际文件并确认保存、恢复和可选复习入口。该检查不是完整学习行为测试。

## 明确限制

- 真人测试尚未完成，尚未证明学习效果提升。V0.2 对照未达到预设明显改善门槛。
- 真实时间跨日第一天已完成，第二天测试尚未完成；模拟时钟不等于真实跨日，开发代理作答不等于真人试用。
- 其他 Agent 未完整验证；主要验证环境为 Codex。其他语言不作全面支持承诺。
- 每份记录只支持一个目标和知识点。数据为未加密本地 JSON，无云同步、后台提醒、数据库或学习者画像。
- 新题相关性、答案理解与错因判断仍依赖模型；本版本是可试用实验，不保证学习成效。
- 本次按维护者授权，接受上述未完成项发布 Pre-release；不表示此前完整验收门槛已全部达到。

## 安装与第一次使用

从本 Release 下载源码 ZIP，解压后将文件夹命名为 ai-study-mentor-skill，使用你的 Agent 的 Skills 安装机制加载完整文件夹。保留 SKILL.md、references/、scripts/ 的相对结构；不要覆盖未经备份的旧安装或同时保留同名两份。

Codex 示例：放到 ~/.agents/skills/，新建聊天，选择 $ai-study-mentor-skill。部分客户端识别 ~/.codex/skills，以实际发现为准。对话不需 Python；本地保存/恢复需 Python 3.10+ 和文件权限，无第三方运行依赖。

发送：“使用 $ai-study-mentor-skill 带我学购物折扣，先了解我的目标和基础。结束时问我要不要保存进度。”

按实际练习作答，结束时确认保存范围与仓库外文件位置。下次新聊天发送：“使用 $ai-study-mentor-skill，恢复我的学习记录。”提供文件路径，核对摘要，再选择继续或复习。新会话保存仍需授权。

完整指南见 examples/真实使用指南.md；填写后的个人反馈与学习文件保存在仓库外，不公开上传。

## English summary

Experimental Agent Skills framework for error diagnosis, consent-based local state saving, cross-session recovery, optional delayed retesting and learning evidence. Automated checks and developer-simulated model cases passed. Real-learner testing and the real-clock second-day test remain incomplete; improved learning outcomes have not been demonstrated. Other Agent environments are not fully verified. Requires Python 3.10+ only for local persistence. v0.1.3 remains the stable release.
