## 可直接用于 Release 的版本说明

AI Study Mentor Skill 的首个早期版本提供一套可由 Codex 执行的微课规则：
学习主题 → 目标与基础 → 简短讲解与例子 → 一道练习 → 根据答案反馈 → 下一步建议。

### 本版包含
- 目标与基础采集，以及根据当前回答调整讲解。
- 跟随用户语言、明确指定语言优先，切换语言保留学习状态；中英文 README。
- 错误解释、不同相关题复测和针对真实答案的反馈。
- 基础不足时降低难度，临时偏题后保持原任务上下文。
- 尊重跳过练习，保持“已讲解、未验证”；不把阅读或单题正确当作整个主题掌握。
- 安装指南、虚构示例、人工验收脚本、公开的 CLI 教学记录与桌面功能验收摘要及 MIT LICENSE。

### 已验证
官方 Skill 格式检查通过；原有 3 项结构检查加上发布准备新增的 2 项内容扫描验证，当前共 5 项通过。
在 Windows Codex CLI 0.160.0、已有 ChatGPT 登录及配置模型 gpt-6.1-sol 下，百分比主题 A–E 行为测试通过。
CLI 的 A 是多轮会话，B–E 从共同的未作答检查点分叉；由开发代理扮演学习者。
桌面手动验收已通过技能发现、显式调用、首轮诊断及 A–E。证据来自维护者逐轮回传，B–E 连续测试，A 的正确作答与新会话诊断来自不同片段。桌面模型与客户端版本未记录，不是真人学习效果研究。

补充多语言实测：英文目标诊断、讲解、练习、错因解释和不同题复测通过；明确英语优先与英转中状态保留通过。修改后中文 A–E 回归通过，见 tests/多语言教学验收.md。使用开发代理扮演学习者、现有 CLI/登录/模型；不是真人长期学习效果研究。

### 已知限制
日语及其他语言、英文独立降低难度/偏题场景未验证。引用规则文件仍为中文。
隐式触发、普通问答误触发和其他主题/模型尚未验证；推荐从技能候选中显式选择。
尚无教材解析、完整课程、三模式、跨会话存储、知识记忆库、网站或可调用 API。
教学结果依赖宿主模型与会话上下文；源码结构检查不证明所有教学行为正确。
V0.2 的好奇心引导和知识点结构仅为规划，没有在本版启用。

安装与调用以 README 为准；不需要额外模型 API 客户端。首次使用可输入：
“使用 $ai-study-mentor-skill 带我学百分比。”
