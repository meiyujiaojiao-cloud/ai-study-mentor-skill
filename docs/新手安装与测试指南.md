# 新手安装与测试指南

## 先确认是否已安装
先从 GitHub 仓库点击绿色 Code → Download ZIP，解压。若下载目录带 -main 或版本后缀，把包含 SKILL.md 的文件夹改名为 ai-study-mentor-skill。
Windows 可按 Win+R，输入 %USERPROFILE%，在打开的个人文件夹中依次建立 .agents、skills，再把整个 ai-study-mentor-skill 文件夹复制进去；文件夹已存在就进入它。其他系统使用个人目录下的 .agents/skills。
这是当前官方推荐路径；若客户端无法发现，按 [README](../README.md) 的版本兼容说明检查 ~/.codex/skills，而不是同时重复安装。
如果之前已经安装，先检查技能候选中是否有 ai-study-mentor-skill；有则不用重复安装。
SKILL.md 必须在技能文件夹的根目录，references、examples、tests、docs 等与它并列。
用普通文件夹复制即可，不需要创建目录链接、安装 Python 或输入程序命令。若同名技能已存在，先比较版本并备份，不直接覆盖。
如果安装采用了指向源码的目录链接，请保留链接目标文件夹；移动目标可能导致失效。

## 打开一个干净的测试聊天
以下依据官方桌面文档编写，尚未查看你的实时屏幕；按钮可能显示中文或英文。
1. 保持在你现在使用的 Codex 桌面应用，不需要打开 GitHub、浏览器 ChatGPT 或安装编程工具。
2. 找到左侧边栏“最近 / Recents”，点击它旁边的“新建聊天 / New chat”（通常是新建图标）。选择本地电脑上的 Codex 聊天；如果应用出现 Chat、Work、Codex 选择，选 Codex。
3. 如果新建界面要求选项目，选择保存本 Skill 或练习资料的本地项目；使用个人技能目录安装时，也可新建不依赖项目的聊天。保持当前本地环境，不选远程/云端环境。
4. 在底部输入框先键入美元符号 $，继续输入 ai-study-mentor-skill。若出现技能列表，点击这个名称，再补上“带我学百分比。”并发送。
5. 如果输入框没有提供候选，也可以完整粘贴下面这句话发送：
   使用 $ai-study-mentor-skill 带我学百分比。
6. 如果提示找不到技能：完全退出 Codex 应用，再重新打开，重新创建聊天并重试。不需要重启 Windows，也不要重装依赖或改变 API 设置。
7. 若重启后仍找不到，请回到开发聊天报告“技能列表找不到”，不要把普通 AI 对话当作本 Skill 已加载。

新会话通常足够；官方文档说更改可自动发现，未出现时再重启。当前开发聊天的技能列表可能仍是旧快照。

## 怎样判断加载成功
- 最直接的用户侧证据：技能候选列表中出现 ai-study-mentor-skill，并选择它。
- 回复通常应说明采用本 Skill，随后只询问目标与基础，等待你的回答。
- 仅说“我会当老师”或恰好问目标，不足以证明已加载。若界面没有展示技能使用信息，可以补发：
  请说明你实际读取的 ai-study-mentor-skill 的 SKILL.md 和教学流程文件路径，并读取后再继续；若没有读到请如实说。
- 本项目已有CLI与维护者桌面验证记录，但你新聊天里的实际加载仍要记录；模型口头声称加载不等于工具读取证据。
- 不需要把密钥、账号信息、私人笔记或教材原件发给它。

## A 正常学习：逐条发送，不要一次粘贴全部
第1条：使用 $ai-study-mentor-skill 带我学百分比。
预期：它问学习目标和基础，不直接替你完成所有步骤。
第2条：我想算购物折扣，会小数乘法。
预期：简短解释，再给一道题，然后停下来等你回答。
第3条：根据它真正出的题回答数值，并解释怎么算。例如“支付原价的75%，所以用原价乘0.75”；不要照抄示例数字。
预期：它按你的答案反馈，最多说本题通过，不宣布百分比全掌握，并建议下一步。

## B 故意答错
另建一个新聊天，重复 A 的前两条。看到折扣题后，故意按“减去折扣比例”算，写出错误理由。
如果它真的出了“200元打七五折”，就回复“50元，因为七五折是减去75%”；如果数据不同，用它的真实数据算错。
预期：解释支付比例与减去比例混淆，给不同数据但相同概念的题复测，等待你回答。再正确作答，检查反馈。

## C 要求更简单
另建新聊天，第1条：
使用 $ai-study-mentor-skill 带我学百分比。我想看懂购物折扣，但没有数学基础。
等它讲完，再发：
完全听不懂，小数乘法也不会。请用更简单的生活例子，一次只讲一步。
预期：换成分物品、小整数等更具体的解释，减少术语，给更小的检查；不能只是重复之前的话。

## D 临时偏题
另建新聊天，重复 A 的前两条，出题后先发：
顺便问一下，为什么天空是蓝色的？
预期：合理简答，适当邀请回到原学习，不强迫答题。
再发：回到刚才的百分比题。
预期：续接尚未回答的题，不编造你的答案或成绩。

## E 跳过练习
另建新聊天，重复 A 的前两条，出题后发：
跳过练习，直接继续讲下一点。
再问：刚才那个知识点算掌握了吗？
预期：同意跳过，能够继续讲，明确已讲解但未验证；不宣布掌握，也不反复逼你答题。

## 把结果发回开发聊天
在自己的测试笔记或项目反馈中记录：
A：通过/失败；B：通过/失败；C：通过/失败；D：通过/失败；E：通过/失败。
技能是否出现在候选列表：是/否。
有问题的场景，我的输入和 AI 回复如下：……
可先做 A，不必一次做完。只复制与你测试有关的文字，去除任何私人信息。
