# V0.4 当前限制

## 已验证范围

本地只读导出已有17项自动检查通过；原有35项连续性、7项文件检查及官方格式验证在初次开发时通过。用户回传一次真实统计学使用结果，支持“原环境导出 → DeepSeek新会话恢复 → 迁移练习 → 返回摘要”的主要手动流程。

该反馈不是开发代理独立复核的原始对话或文件审计，也不是学习效果研究。保留用户确认的结果和失败，不扩大到所有主题、模型或客户端。

## 已知问题

返回摘要将一次未完成追问误记为“提示后完成”。已补充指令和人工核对规则：没有实际知识作答，就无新增知识证据，不改变对应验证状态。其他已实际完成练习的历史及新增证据继续保留。

规则修改不等于DeepSeek行为已经修复；新版指令仍需实际复测。本地存储器不能自动判断摘要是否真实，不能仅凭一段提示词保证杜绝误记。此次未修改用户的私人学习记录。

## 尚未完成

- 修正后对未答追问、仅提供提示及提示后实际作答的对照复测。
- 返回原环境人工核对、明确授权、成功保存、重新读取及新会话恢复的完整往返。
- 原定数学折扣和Python列表索引案例。
- 本次真实24小时延迟、英文DeepSeek、长记录与其他运行环境验证。

## 功能边界

- DeepSeek目前仅为手动接续验证，不是自动接入、原生Skill安装或云同步。
- 普通对话不能凭本地路径访问电脑，也不能声称已保存本地记录。
- 只支持V0.3单目标/单知识点 learning-state.json。没有多课程、API、数据库、多Agent或Core重构。
- JSON副本保留兼容；返回结果是待核对摘要，没有自动导入或合并。
- 外部时间需用户核对；未知间隔不算延迟复测，导出/复制时间不能当作作答时间。
- 当前指令与指南为中文，不据此声称完整英文DeepSeek回归。

## 隐私与效果

个人记录、导出和返回片段应保存在仓库外，不进入公开Git。发送至DeepSeek前由用户审阅；远程服务的数据处理不等于纯本地存储。不要公开完整学习对话、个人路径或凭据。

已经有一次用户实际操作反馈，但没有足以证明学习效果提升的数据。自动检查、模型模拟、用户实际体验与原始文件核对须分别描述。

验收详情见 [实际验收记录](../tests/V0.4最小接续验收.md)。
