# 校园介绍文案（草稿，可用于班级群或社团分享）

## 试试让 AI 陪你讲一小段、练一道、检查理解

AI Study Mentor 是一个实验性 AI 学习助手，适合想弄懂课程概念、愿意尝试练习，也希望下次接着学的同学。

你可以在 DeepSeek 新对话中粘贴教学指令，说出自己的目标和基础，然后按“讲解 → 练习 → 错误反馈 → 新题检查”的流程学习。不懂可以要求讲简单一点，也可以跳过或暂停。

结束时，让它生成学习摘要，自己复制到备忘录；下次把指令和摘要带回新对话，核对后继续。读过、提示后答对和独立完成，应当分别记录。

目前为 V0.4 实验开发版，采用手动复制方式，没有自动接入或保存。已有一次统计学手动接续反馈，仍发现过摘要误记，其他场景需要继续验证；不保证成绩提升。

想试用，请同时领取“教学指令”和“普通学生使用指南”，先从一个小知识点开始。使用后欢迎反馈：哪里不清楚、摘要有没有写错、下次能不能接上。
