# DeepSeek 手动接续：最小使用指南

本功能用于从当前学习环境带出一份 V0.3 学习记录，在 DeepSeek 普通对话中继续，再带回核对。没有自动导入、同步或 API；DeepSeek 不会因此获得本地文件权限。Codex 是已验证的 Skill 环境示例，不是必需的模型。

## 1. 在原环境保存并导出

正常学习后说：“请保存我的学习进度。”核对保存范围，选择仓库外位置并明确授权。只在工具报告成功后进行导出。

然后说：“请读取我明确指定的学习记录，使用只读导出工具导出 Markdown 和 JSON 副本到一个新的仓库外目录。不要修改源记录。”提供源记录的完整路径及你选择的新导出目录。不搜索私人文件；不知道路径就先查自己之前保存的回复。

愿意手动运行工具的用户可使用 Python 3.10+：

```powershell
python -X utf8 scripts/export_learning.py --path "<记录的完整路径>" --output-dir "<新的导出目录完整路径>"
```

尖括号内容须替换为实际路径。两项路径都必须明确提供，导出目录不能已存在或位于 Git 仓库。工具只接受已保存且有效的 learning-state.json，不支持未完成开发的多课程学习库。

成功产生“学习接续记录.md”和原始“learning-state.json”副本；原文件不变。JSON 副本不要另行编辑或当作新主记录保存，避免分叉。导出副本含学习摘要，请在发送前检查是否含私人信息；发送给 DeepSeek 的内容会进入该服务，不是纯离线处理。

## 2. 复制教学指令

打开 [DeepSeek教学指令](DeepSeek教学指令.md)，复制全文。

打开你自己的 DeepSeek 网页或应用，新建一个对话，将全文粘贴发送。这里只使用普通对话指令，不宣称是系统权限或原生技能安装。

## 3. 提供学习记录

打开导出的“学习接续记录.md”，复制全文并发送。优先粘贴；若你所用界面有附件功能，也可以上传 Markdown 或 JSON 副本，并要求它确认读到的目标和修订号。附件不支持或识别不完整时改为粘贴，不仅发送电脑路径。

随后发送：

> 请只根据这份记录展示上次目标、知识点、状态、未完成问题和下一步，先等我确认，不要给未答题答案，也不要声称保存。

检查摘要和原记录一致后，发送“继续未完成问题”，或“先复习，请出不同但相关的新题，不要给答案”。正常回答；请求过提示就保留提示片段，不要把它描述为独立作答。

## 4. 取得返回摘要

结束时发送：

> 请按教学指令给出返回摘要：本次完整题目、我的回答与理由、提示情况、反馈、未完成问题、下一步及原修订号。没有可靠作答时间就写待核对。不要重写历史 JSON；明确说明尚未保存到本地。

保留题目、自己回答及提示的必要片段，供原环境核对；不需要复制全部聊天。

## 5. 带回原环境人工核对

回到能使用原存储工具的环境，明确提供主记录路径、返回摘要及必要片段，发送：

> 这是我在 DeepSeek 的学习返回摘要。请重新读取主记录，核对原修订号、历史、题目、实际答案和提示情况，展示拟保存变化，先不要写入。信息不足请问我。

原环境应独立核对答案和理由，不照搬外部“已掌握”结论。若源记录已变化、目标改变、遗漏提示或时间不明，应先澄清，不能直接覆盖或强行合并。V0.3 单文件只有一个目标与知识点，更换范围要另选记录位置。

核对时先排除没有实际知识作答的互动：请求解释或询问时间、已提供提示但未回答、未完成追问，都不能记为“提示后完成”。这些互动只列为未完成问题，无新增知识证据，不改变对应验证状态；保留其他真实练习的新增证据。不要因修正这个错误抹去原有或本次真实作答。

确认变化后，你再明确授权保存。继续使用原 learning_store.py、最新修订号和安全写入流程；不增加自动导入接口。保存成功后重新读取核对新增内容与历史保留情况。失败就说明未保存，保留返回摘要，勿反复覆盖。

**时间规则：**不要把复制、导出或导入时间当成实际答题时间。外部作答时间需要你核对；无法确认时不追加带猜测时间的证据、不宣称延迟通过。可先保留待核对摘要或明确授权只更新暂停位置。延迟复测仍遵循原规则，由工具和真实证据判断。

## 常见问题

- DeepSeek 说“已保存”：没有本地工具成功结果就不算保存，请要求改成“返回摘要尚未保存”。
- 没有历史证据：可能尚未实际作答或未保存；不能让模型补造。
- 找不到未完成题：先核对导出和主记录，可能之前没有成功保存。
- 内容过长或粘贴不全：暂停本次接续，不让模型根据残缺记录宣称恢复完整；本版不做自动压缩。
- 导出目录已存在：换一个新目录，工具不会覆盖已有文件。
- 这是云同步吗：不是，只有一份本地主记录，其他文件是手动传递副本。

实际测试步骤见 [V0.4最小接续验收](../tests/V0.4最小接续验收.md)。统计学手动接续已收到用户实际操作反馈：恢复和返回摘要的主要检查通过，但发现未作答追问被误记为提示后完成，已补充规则；修正后行为仍待复测。数学折扣、Python及返回后本地保存/再恢复仍待验证。此结果不代表自动接入、所有主题兼容或学习效果验证。
