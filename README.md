# AI Study Mentor Skill

[English](README.en.md) | [简体中文](README.md)

**v0.3.0-experimental.1 · Pre-release · [已发布稳定版 v0.1.3 · GitHub Release](https://github.com/meiyujiaojiao-cloud/ai-study-mentor-skill/releases/tag/v0.1.3)**

**AI Study Mentor 是一个面向 AI 开发者和 Agent 使用者的实验性自适应学习框架**，以 Agent Skills 的指令与参考文件组织教学流程，供构建 AI 学习助手时使用。本实验版本为 v0.3.0-experimental.1，在 V0.2 错因诊断基础上提供授权保存、恢复和不同相关题复习。
框架使用“学习主题 → 目标与基础 → 简短讲解 → 一道练习 → 答案反馈 → 下一步”的流程。阅读和跳过练习不会被当作掌握证据；一次答对只验证本题。

## 面向谁，以及如何使用

- **AI 开发者**：研究或集成错因诊断、学习证据和学习连续性规则。
- **Agent 使用者**：在支持 Skills 的 Agent 环境中加载教学流程并参与实验验证。
- **想构建 AI 学习助手的人**：复用和调整规则，作为自己的学习助手实现基础。

本仓库定位为框架与 Skill 组件，使用者需要能够配置 Agent 环境。**Study Mentor Web 是面向普通学生的产品入口**；它是独立产品，不包含在本 Skill 仓库中，其功能和可用状态以 Web 项目说明为准。

教学规则以文本文件组织，目标是供支持 Agent Skills 的环境复用。当前安装与行为验证主要在 Codex 中完成，不代表已验证所有 Agent 的兼容性；其他环境需核对技能发现、引用加载、文件权限，以及本地保存所需的 Python 执行能力。

本次发布说明与限制见 [V0.3 实验版本说明](docs/V0.3实验版本说明.md)。v0.1.3 继续作为 Stable；真人试用和真实时间跨日第二天仍未完成。

## 为什么解释不一定带来理解

普通 AI 可以给出清楚的解释，也可能主动调整教学；但仅凭一次问答，仍可能不知道用户为什么错、缺少判断真实理解程度的证据，或继续采用不适合用户的讲解方式。解释正确不等于学习者已经理解。

V0.2 尝试让调整过程更明确：

- **错因分类**：依据作答与理由区分概念、题意、计算、基础和推理问题；证据不足时先诊断，不急着定性。
- **针对性解释**：根据当前错因选择对照例子、拆解步骤或补一个必要基础。
- **不同题复测**：用相关但不同的题目获取新的理解证据。
- **根据反馈调整**：随后续回答更新判断和教学方式，保留用户跳过或改变目标的选择。

**V0.2 目前只有模拟案例验证，没有真人学习数据。** 这些规则是待检验的设计，尚未证明能提升真实学习效果，也未达到本轮对旧版明显改善的预定门槛。详见 [V0.2 实验报告](tests/V0.2对比报告.md)。

## V0.3 Phase 3：保存、恢复与可选复习

首次说“请保存我的学习进度”，Skill 会说明保存的必要摘要，并请你选择仓库外目录、确认后才写入。不保存完整聊天或教材；拒绝保存时仍可正常学习。使用存储工具需要 Python 3.10 或更高版本，无第三方依赖。

新建聊天，选择本 Skill，发送“继续上次学习”，并提供之前的 learning-state.json 完整路径。Skill 读取成功后展示目标、验证状态和下一步，等待你选择继续、复习或更换目标。继续时会保留未回答问题；存在到期复习项时会提供“先复习／继续学习／更换目标”，由你选择。复习使用不同相关题，不提前给答案。

没有明确路径时不会扫描文件；没有记录或读取失败时不会编造历史。保存失败会明确告知未保存。详见 [授权保存与学习恢复](references/学习连续性.md)。实际作答保存后可建议次日复习；距最近作答至少24小时的新题才记延迟复测。独立正确记延迟通过，提示后正确不算独立通过，答错进入原有错因诊断并保留历史，跳过不改状态。延迟独立通过后建议3天后再检查，其他复测建议次日。这些间隔是实验规则，不是已验证遗忘模型；没有后台提醒、画像或方法推荐。见 [复习规则](references/自适应复习.md)、[Phase 2 验收](tests/V0.3连续性验收.md) 和 [Phase 3 验收](tests/V0.3第三阶段验收.md)。

本阶段验收：35项存储/恢复/复习自动检查及7项文件检查通过，两个独立会话模型案例完成。延迟时间使用明确模拟时钟，尚无完整真实跨日或真人验证；这是历史阶段验收结果，详见 Phase 3 验收。

发布前补充验收：英文首次学习、授权保存、独立恢复、同日不同题复习及英转中状态保持通过；中文 A–E 独立会话回归通过。真实跨日第一天已按真实时钟完成，第二天尚待满24小时；3人试用仅完成方案。最新结果见 [发布前验收](tests/V0.3发布前验收.md)，完整验收仍有未完成项；维护者接受这些限制发布 Pre-release，不表示完整验收通过。

个人试用请从 [真实使用指南](examples/真实使用指南.md) 开始；使用后可填写仓库外的 [个人记录模板](tests/个人真实使用记录模板.md) 副本。请从 [V0.3 Pre-release](https://github.com/meiyujiaojiao-cloud/ai-study-mentor-skill/releases/tag/v0.3.0-experimental.1) 下载此版本；v0.1.3 稳定版下载不包含这些连续性能力。

## 安装与开始

先按所用 Agent 的技能安装机制加载完整文件夹，保留 SKILL.md、references/ 与 scripts/ 的相对结构。以下是本项目已验证的 **Codex 安装示例**，目录和调用语法不应直接套用到其他客户端。

1. 下载或克隆本仓库，保留完整的 ai-study-mentor-skill 文件夹。SKILL.md 应在该文件夹根目录，不要多套一层同名目录。
2. 把完整文件夹放入你的 Codex 技能目录；目标同名目录存在时先比较，不直接覆盖。
3. 当前官方文档列出用户目录 ~/.agents/skills 或项目内 .agents/skills。部分客户端仍扫描 ~/.codex/skills；本项目在 Windows Codex CLI 0.160.0 上验证过该兼容目录，并在独立临时项目中确认 .agents/skills 能被原生发现。以当前客户端的 /skills 或技能候选列表实际发现为准，不需要同时安装到多个位置。
4. 新建 Codex 聊天，在技能候选中选择 ai-study-mentor-skill，或发送：

> 使用 $ai-study-mentor-skill 带我学百分比。

回答目标和基础，再根据它实际出的练习作答并解释理由。技能未出现时重启 Codex，检查文件夹层级及安装位置；不要只凭普通 AI 回复就认定已加载。
如需检查目录里的指令，可明确让 Codex 读取 SKILL.md 及相对引用；手动读取测试不等于原生技能发现成功。

详细桌面步骤见 [新手安装与测试指南](docs/新手安装与测试指南.md)。
本 Skill 不附带模型 API 客户端、不要求新增依赖；Agent 运行环境、账号和模型服务由使用者自行提供，可能受现有服务额度限制。

## 功能与边界
已编写的规则包括：采集目标与自述基础、单知识点讲解、练习与理由、错误纠正和不同题复测、降低难度、回应临时偏题、尊重跳过并保留未验证状态。
未授权保存时状态仅在当前对话中维护；授权后只恢复最后成功保存的摘要，见 [状态与扩展约定](references/状态与扩展约定.md)。

尚未实现：教材文件解析、自动生成完整课程、完整诊断测评、三模式、云端持久化、知识记忆库与可调用 API。本仓库不包含 Study Mentor Web 的实现。
[V0.2 方案](docs/V0.2设计规划.md) 将本轮范围限定为错因诊断：概念、题意、局部计算、前置知识、推理缺口与证据不足；原因未知时先问一个诊断问题，随新解释更新。好奇心引导、长期记忆等不在本轮实现。
诊断规则见 [错因诊断](references/错因诊断.md)。规则改进不等于已经证明比普通模型更有效，实测比较见 [V0.2 对比报告](tests/V0.2对比报告.md)。

## 验证与证据
在项目目录运行零依赖文件检查：

```powershell
python tests/验证文件.py
```

检查 frontmatter、本地引用、必要文件、常见凭据与真实本机绝对路径，并自测扫描样例；这不是全面秘密扫描，也不执行模型教学。还可运行 Codex skill-creator 提供的 quick_validate.py，其验证环境需要 PyYAML，本项目运行不依赖它。
行为测试步骤见 [人工教学验证](tests/人工教学验证.md)，虚构示范见 [百分比教学示例](examples/百分比教学示例.md)。

V0.1.2 实际 CLI 测试 A–E 通过，见 [真实教学验收记录](tests/真实教学验收记录.md)：
- A：先采集目标基础，再讲解、出题、反馈和建议下一步。
- B：解释错误，换一道相关题复测，再根据回答反馈。
- C：用户听不懂时，改用小整数生活例子并缩小检查。
- D：回应临时偏题，回来时保留原题与未作答状态。
- E：同意跳过练习，并明确已讲解未验证。

测试由开发代理扮演学习者，在一个百分比主题、多轮 CLI 会话和四个隔离分支中执行；不是五次冷启动或真人学习效果研究。
v0.1.3 官方检查器与 5 项文件检查曾通过。本分支新增固定案例与CLI事件完成状态检查，共 7 项；最新运行状态见 V0.2 对比报告，结构检查独立于教学行为证据。
V0.1.3 补充桌面手动验收：技能候选发现、显式调用、首轮诊断及 A–E 通过，见 [桌面教学验收记录](tests/桌面教学验收记录.md)。证据是维护者逐轮操作回传；B–E 连续测试，A 的诊断与正确作答来自不同片段，不宣称五次独立冷启动。桌面模型与客户端版本未记录。
隐式触发及普通问题误触发仍未测试，本版推荐显式选择技能；不能推广为所有主题、模型或客户端都通过。

## 教学语言
默认跟随用户输入语言，明确指定语言优先；切换语言仍保留当前题目和验证状态，并使用自然、适合情境的例子。
中文有既有 CLI 与桌面 A–E 验收；英文及语言切换的最新实测结果见 [多语言教学验收](tests/多语言教学验收.md)。日语和其他语言未经过真实测试，不承诺全面支持。

## V0.2 对照与限制
[固定的12个案例](tests/V0.2案例.json) 覆盖数学与Python，[预定评分标准](tests/V0.2评分标准.md) 对比普通Codex、冻结v0.1.3与本分支。[执行器](tests/运行对照测试.py) 使用已登录Codex CLI，原始结果必须存仓库外；评审需要语义判断，不按关键词自动判教学成功。复现隔离与命令见对比报告。
所有新增行为测试由开发代理扮演学习者；没有新的真实学习者测试。每例一次、同一开发代理评审，存在主观偏差与模型随机性，不能证明学习效果或所有主题泛化。当前安装若仍使用稳定版，不会自动改为本评审工作区；安装方式不变，替换前先备份，不能同时装同名两份。

本轮结果：留出集普通Codex 8.50、v0.1.3 9.50、V0.2 10.00（满分10）；**未达到相对两个基线都至少提高1分的预定门槛**。官方检查器及7项文件检查通过，但模型额度耗尽，V0.2中文完整A–E和英文新会话/语言切换回归尚未完成。请先使用已发布稳定版，本分支等待验收。
