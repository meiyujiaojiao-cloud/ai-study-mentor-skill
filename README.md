# AI Study Mentor Skill

[English](README.en.md) | [简体中文](README.md)

**V0.6.3 Experimental · [v0.6.3-experimental.1 Release](https://github.com/meiyujiaojiao-cloud/ai-study-mentor-skill/releases/tag/v0.6.3-experimental.1) · [Stable v0.1.3](https://github.com/meiyujiaojiao-cloud/ai-study-mentor-skill/releases/tag/v0.1.3)**

AI Study Mentor 是面向个人学习、AI开发者和Agent使用者的实验性自适应学习框架。本版本在原教学、错因诊断和学习连续性基础上新增：

- **教材导入**：读取用户指定PDF/PPTX/TXT，先提取章节草稿，用户确认后建立课程；旧PPT需转换，无扫描PDF OCR，不自动下载或上传。
- **多维学习评估**：概念理解、专业表达、应用与迁移分别观察，表达缺漏留待验证，不反复追问或删除历史证据。
- **可选学习笔记**：基于本次真实过程，区分教材、本人表达、作答证据和AI建议；授权保存时新增文件，不覆盖历史、不改变学习状态。

**普通用户流程：教材导入 → 学习 → 完成阶段 → 生成复习笔记（可选） → 保存学习进度 → 下次恢复。** 详见 [普通学生指南](docs/普通学生使用指南.md)、[笔记指南](docs/V0.6.3学习笔记使用指南.md) 和 [本次发布说明](docs/v0.6.3-experimental.1发布说明.md)。

167项自动检查和官方Skill格式验证通过；未完成大规模真人测试，笔记质量、四维判断和真实课程连续性仍需使用验证，尚未证明学习效果提升。后文旧版本验收是历史记录，不代表本版本新功能已经完成真人验证。

本地教材导入/保存需要支持文件和Python工具的Agent环境；普通DeepSeek仅按 [手动接续指南](docs/DeepSeek使用指南.md) 复制指令和摘要，没有自动接入，独立旧指令不会自动获得四维评估或笔记模块。Stable标签保持不变。

## 面向谁，以及如何使用

- **AI 开发者**：研究或集成错因诊断、学习证据和学习连续性规则。
- **Agent 使用者**：在支持 Skills 的 Agent 环境中加载教学流程并参与实验验证。
- **想构建 AI 学习助手的人**：复用和调整规则，作为自己的学习助手实现基础。

本仓库提供框架与Skill组件；完整本地功能需要可配置的Agent环境，普通用户可先按中文指南选择合适入口。**Study Mentor Web 是面向普通学生的产品入口**；它是独立产品，不包含在本 Skill 仓库中，其功能和可用状态以 Web 项目说明为准。

教学规则以文本文件组织，目标是供支持 Agent Skills 的环境复用。当前安装与行为验证主要在 Codex 中完成，不代表已验证所有 Agent 的兼容性；其他环境需核对技能发现、引用加载、文件权限，以及本地保存所需的 Python 执行能力。

历史V0.3范围见 [旧实验版本说明](docs/V0.3实验版本说明.md)。当前范围与未完成项以本页顶部的V0.6.3发布说明为准。

## 为什么解释不一定带来理解

普通 AI 可以给出清楚的解释，也可能主动调整教学；但仅凭一次问答，仍可能不知道用户为什么错、缺少判断真实理解程度的证据，或继续采用不适合用户的讲解方式。解释正确不等于学习者已经理解。

V0.2 尝试让调整过程更明确：

- **错因分类**：依据作答与理由区分概念、题意、计算、基础和推理问题；证据不足时先诊断，不急着定性。
- **针对性解释**：根据当前错因选择对照例子、拆解步骤或补一个必要基础。
- **不同题复测**：用相关但不同的题目获取新的理解证据。
- **根据反馈调整**：随后续回答更新判断和教学方式，保留用户跳过或改变目标的选择。

**V0.2 目前只有模拟案例验证，没有真人学习数据。** 这些规则是待检验的设计，尚未证明能提升真实学习效果，也未达到本轮对旧版明显改善的预定门槛。详见 [V0.2 实验报告](tests/V0.2对比报告.md)。

## V0.3 Phase 3：保存、恢复与可选复习

首次说“请保存我的学习进度”，Skill 会说明保存的必要摘要，并请你选择仓库外目录、确认后才写入。不保存完整聊天或教材；拒绝保存时仍可正常学习。使用存储工具需要 Python 3.10 或更高版本，无第三方依赖。

新建聊天，选择本 Skill，发送“继续上次学习”，并提供之前的 learning-state.json 完整路径。Skill 读取成功后展示目标、验证状态和下一步，等待你选择继续、复习或更换目标。继续时会保留未回答问题；存在到期复习项时会提供“先复习／继续学习／更换目标”，由你选择。复习使用不同相关题，不提前给答案。

没有明确路径时不会扫描文件；没有记录或读取失败时不会编造历史。保存失败会明确告知未保存。详见 [授权保存与学习恢复](references/学习连续性.md)。实际作答保存后可建议次日复习；距最近作答至少24小时的新题才记延迟复测。独立正确记延迟通过，提示后正确不算独立通过，答错进入原有错因诊断并保留历史，跳过不改状态。延迟独立通过后建议3天后再检查，其他复测建议次日。这些间隔是实验规则，不是已验证遗忘模型；没有后台提醒、画像或方法推荐。见 [复习规则](references/自适应复习.md)、[Phase 2 验收](tests/V0.3连续性验收.md) 和 [Phase 3 验收](tests/V0.3第三阶段验收.md)。

本阶段验收：35项存储/恢复/复习自动检查及7项文件检查通过，两个独立会话模型案例完成。延迟时间使用明确模拟时钟，尚无完整真实跨日或真人验证；这是历史阶段验收结果，详见 Phase 3 验收。

发布前补充验收：英文首次学习、授权保存、独立恢复、同日不同题复习及英转中状态保持通过；中文 A–E 独立会话回归通过。真实跨日第一天已按真实时钟完成，第二天尚待满24小时；3人试用仅完成方案。最新结果见 [发布前验收](tests/V0.3发布前验收.md)，完整验收仍有未完成项；维护者接受这些限制发布 Pre-release，不表示完整验收通过。

个人试用请从 [真实使用指南](examples/真实使用指南.md) 开始；使用后可填写仓库外的 [个人记录模板](tests/个人真实使用记录模板.md) 副本。V0.3历史能力可从 [旧Pre-release](https://github.com/meiyujiaojiao-cloud/ai-study-mentor-skill/releases/tag/v0.3.0-experimental.1) 查阅；本次安装请下载顶部V0.6.3版本；v0.1.3 稳定版下载不包含这些连续性能力。

## 安装与开始

先按所用 Agent 的技能安装机制加载完整文件夹，保留 SKILL.md、references/ 与 scripts/ 的相对结构。以下是本项目已验证的 **Codex 安装示例**，目录和调用语法不应直接套用到其他客户端。

1. 从顶部V0.6.3 Release下载版本文件，不用main分支的旧版；解压并将完整文件夹命名为ai-study-mentor-skill。SKILL.md 应在该文件夹根目录，不要多套一层同名目录。
2. 把完整文件夹放入你的 Codex 技能目录；目标同名目录存在时先比较，不直接覆盖。
3. 当前官方文档列出用户目录 ~/.agents/skills 或项目内 .agents/skills。部分客户端仍扫描 ~/.codex/skills；本项目在 Windows Codex CLI 0.160.0 上验证过该兼容目录，并在独立临时项目中确认 .agents/skills 能被原生发现。以当前客户端的 /skills 或技能候选列表实际发现为准，不需要同时安装到多个位置。
4. 新建 Codex 聊天，在技能候选中选择 ai-study-mentor-skill，或发送：

> 使用 $ai-study-mentor-skill 带我学百分比。

回答目标和基础，再根据它实际出的练习作答并解释理由。技能未出现时重启 Codex，检查文件夹层级及安装位置；不要只凭普通 AI 回复就认定已加载。
如需检查目录里的指令，可明确让 Codex 读取 SKILL.md 及相对引用；手动读取测试不等于原生技能发现成功。

详细桌面步骤见 [新手安装与测试指南](docs/新手安装与测试指南.md)。
本 Skill 不附带模型 API 客户端、不要求新增依赖；Agent 运行环境、账号和模型服务由使用者自行提供，可能受现有服务额度限制。

## 功能与边界
已编写的规则包括：采集目标与自述基础、单知识点讲解、练习与理由、错误纠正和不同题复测、降低难度、回应临时偏题、尊重跳过并保留未验证状态。
未授权保存时状态仅在当前对话中维护；授权后只恢复最后成功保存的摘要，见 [状态与扩展约定](references/状态与扩展约定.md)。

公开v0.3尚未实现：教材文件解析、自动生成完整课程、完整诊断测评、三模式、云端持久化、知识记忆库与可调用 API。本仓库不包含 Study Mentor Web 的实现。
[V0.2 方案](docs/V0.2设计规划.md) 将本轮范围限定为错因诊断：概念、题意、局部计算、前置知识、推理缺口与证据不足；原因未知时先问一个诊断问题，随新解释更新。好奇心引导、长期记忆等不在本轮实现。
诊断规则见 [错因诊断](references/错因诊断.md)。规则改进不等于已经证明比普通模型更有效，实测比较见 [V0.2 对比报告](tests/V0.2对比报告.md)。

## 验证与证据
在项目目录运行零依赖文件检查：

```powershell
python tests/验证文件.py
```

检查 frontmatter、本地引用、必要文件、常见凭据与真实本机绝对路径，并自测扫描样例；这不是全面秘密扫描，也不执行模型教学。还可运行 Codex skill-creator 提供的 quick_validate.py，其验证环境需要 PyYAML，本项目运行不依赖它。
行为测试步骤见 [人工教学验证](tests/人工教学验证.md)，虚构示范见 [百分比教学示例](examples/百分比教学示例.md)。

V0.1.2 实际 CLI 测试 A–E 通过，见 [真实教学验收记录](tests/真实教学验收记录.md)：
- A：先采集目标基础，再讲解、出题、反馈和建议下一步。
- B：解释错误，换一道相关题复测，再根据回答反馈。
- C：用户听不懂时，改用小整数生活例子并缩小检查。
- D：回应临时偏题，回来时保留原题与未作答状态。
- E：同意跳过练习，并明确已讲解未验证。

测试由开发代理扮演学习者，在一个百分比主题、多轮 CLI 会话和四个隔离分支中执行；不是五次冷启动或真人学习效果研究。
v0.1.3 官方检查器与 5 项文件检查曾通过。本分支新增固定案例与CLI事件完成状态检查，共 7 项；最新运行状态见 V0.2 对比报告，结构检查独立于教学行为证据。
V0.1.3 补充桌面手动验收：技能候选发现、显式调用、首轮诊断及 A–E 通过，见 [桌面教学验收记录](tests/桌面教学验收记录.md)。证据是维护者逐轮操作回传；B–E 连续测试，A 的诊断与正确作答来自不同片段，不宣称五次独立冷启动。桌面模型与客户端版本未记录。
隐式触发及普通问题误触发仍未测试，本版推荐显式选择技能；不能推广为所有主题、模型或客户端都通过。

## V0.4起保留的手动接续

在当前 Skill 环境保存后，使用 [只读导出工具](scripts/export_learning.py) 导出 Markdown 接续记录和原始 JSON 副本，再将 [通用教学指令](docs/DeepSeek教学指令.md) 与记录粘贴到 DeepSeek。返回摘要带回原环境，人工核对并授权后才按 V0.3 原工具保存。步骤见 [DeepSeek 使用指南](docs/DeepSeek使用指南.md)，实测状态见 [接续验收](tests/V0.4最小接续验收.md)。

Codex 是已验证环境示例；通用指令不需要 Codex 或本地路径。普通 DeepSeek 对话不能因此读取电脑文件或自动保存。本功能不调用 API、不自动导入或同步、不支持未完成的多课程系统。导出使用 Python 3.10+ 标准库，源 V0.3 格式与教学、保存、复习逻辑保持不变。已收到统计学 DeepSeek 手动接续的用户实际反馈：恢复与返回摘要主要检查通过，但发现未作答追问被误记为提示后完成；已补充指令，修正后复测、本地返回保存与数学/Python案例仍待验证。不能把自动导出检查当作教学成功。个人导出放仓库外，发送前检查隐私。

## V0.4.1起保留的体验测试准备

本轮只优化使用入口、反馈和测试支持，沿用现有教学和存储逻辑，没有新增学习算法、画像、数据库或网站功能。[5分钟首次测试流程](docs/首次使用测试流程.md) 区分独立成功、协助后成功、未成功与无法判断；完整学习、手动保存及新对话恢复单独观察，不要求在5分钟内全部完成。

反馈使用 [用户反馈收集表](docs/用户反馈收集表.md)，观察记录使用 [真人测试空白模板](tests/V0.4.1真人测试记录模板.md)。填写后的个人副本保存在仓库外，不公开完整聊天或个人信息；匿名引用需同意。V0.4既有统计学反馈不计为V0.4.1新测试，本轮没有新增真人结果，等待实际反馈，不据此宣称普遍易用或学习效果提升。

## V0.5 个人学习版

数据与代码分离，知识点各自使用原V0.3记录、保存及复习工具。课程切换保留各自未答题与证据；教材只登记名称、用户指定位置、章节和目标，不自动读取内容。把用户指定学习库作为本地项目打开，或明确提供其学习入口文件后，可发送“继续学习”恢复摘要，确认后继续。无项目上下文的任意聊天不能自动发现私人目录；DeepSeek普通对话仍使用手动接续。

实现与权限见 [个人学习库约定](references/个人学习库.md)，自动检查见 [文件操作测试](tests/个人学习库验证.py)，本人跨日使用见 [连续使用验收](tests/V0.5个人连续使用验收.md)。没有模型模拟用户测试；真人跨日和课程切换尚待本人反馈。无画像、数据库、云同步、自动计划或后台提醒，不声称学习效果提升。

## V0.6 教材与课程入口

新增课程向导、教材元数据和独立章节管理。教材可无文件登记，作者/出版/ISBN等未知不猜测；仅登记模式记录文件名、用户版本与修改时间；用户主动指定PDF/PPTX/TXT并要求导入时，本地提取目录草稿，确认后才写入章节和教材关联。旧PPT须先另存为PPTX，扫描PDF无OCR，不做整书语义理解或自动复制上传。PDF需要运行环境已有pypdf；缺失会提示，不自动安装。见 [教材导入指南](docs/教材导入指南.md)。来源说明不等于验证版权，不自动接入ChinaTextbook等仓库或下载资源。

V0.5索引和V0.3记录不变，course.json与material.json只是私人入口补充；课程目标和章节以索引为准，证据以原记录为准，投影过期会提示。详情见 [操作约定](references/教材与课程入口.md) 与 [验收记录](tests/V0.6教材课程入口验收.md)。真实教材、本人学习和次日恢复仍待实际执行，自动文件检查不是教学或学习效果验证；DeepSeek接续不变，没有数据库、画像、提醒、云同步或自动全年规划。

## V0.6.1 学习体验优化

练习优先基于实际读到的当前教材章节与知识点，采用应用、情境或迁移题，未读教材时标明知识点原创；题目类型、来源章节、迁移标记随原task_summary文本保留，不新增字段或改写旧证据。反馈只展示可观察结论、必要解释与下一步，不展示内部思考草稿。结束可选择八项学习总结，恢复提供欢迎、真实位置与建议，并等待确认；未答题保留，总结不替代证据或保存。考试/理解/探索仅是用户选择的当前对话侧重点，不是学习画像，不自动跨会话记忆。

规则见 [学习体验](references/学习体验.md)，测试见 [真人验收](tests/V0.6.1真实体验验收.md)。本轮没有修改存储脚本、核心结构、错因原则、教材导入或DeepSeek手动接续指令；独立DeepSeek指令没有自动获得这些优化。自动兼容性检查不证明题目质量或真人体验。

## V0.6.2 分项教学评估

概念理解、专业表达、应用与迁移分别依据真实作答展示已验证/待验证及具体范围。考试模式兼顾专业复述、自己的解释和应用；一个表达缺漏不抹去正确理解，允许继续并在后续关联任务自然检查，真实错误仍按原错因流程处理。不做隐瞒用途的测评、总分或总掌握判决。复习选择与实际不足相符的不同任务，仍沿用原时间、提示及自主选择规则。

观察写入原response_summary文本，用户理由仍单独保留、缺失为null；不新增数据字段，不改历史或工具。原verification_status不是四维总评，旧证据无分项标签时需核对实际表现。详情见 [评估规则](references/教学评估.md) 与 [验收记录](tests/V0.6.2教学评估验收.md)。这些是Agent教学规则，不是自动评分引擎；独立DeepSeek指令未修改，真人体验待验证。

## V0.6.3 可选学习笔记

结束只提供一次“生成复习笔记/继续学习/暂不生成”，不默认生成。笔记包含本次核心知识、我的理解、真实易错点、已验证/待验证能力、实际题目与回答、下次建议；未知内容不补编，AI补充不得冒充用户理解。实际课程/章节/知识点和证据关联注明，未保存则说明来自本次对话。

生成先展示，文件写入需授权内容与私人位置；新笔记单独保存不覆盖旧文件，删除笔记不删除证据。原状态恢复、保存、评估、教材导入及DeepSeek接续均不变。见 [笔记约定](references/学习笔记.md)、[模板](examples/学习笔记模板.md) 和 [验收](tests/V0.6.3学习笔记验收.md)。工具仅保存笔记，不自动验证语义；真人内容质量待验证，独立DeepSeek指令未更新。
