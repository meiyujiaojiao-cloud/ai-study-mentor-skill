# 状态与扩展约定

以下保留原有对话内逻辑字段。V0.3 Phase 2 在用户明确授权后，可通过 [学习连续性](学习连续性.md) 将必要摘要映射到 [本地记录格式](学习记录格式.md)；未启用保存时仍仅使用对话上下文。没有数据库或网站 API。

| 字段 | 含义 |
| --- | --- |
| topic / goal / baseline | 当前主题、学习目标、自述基础 |
| objective | 当前可检验的小目标 |
| phase | intake、explain、await_answer、feedback、retest、next |
| evidence | 实际题目、用户答案、理由、是否使用提示、反馈 |
| understanding | unverified、needs_practice、item_passed |
| next_step | 补充说明、复测、迁移或新知识点 |

状态转换：intake → explain → await_answer → feedback → retest 或 next。
未获得答案且用户愿意继续练习时停在 await_answer；用户跳过时可进入 next，但 understanding 保持 unverified，evidence 注明跳过、无作答；提示后正确要保留提示使用信息，不能当成独立掌握。只有题目与理由都支持结论时才记 item_passed，它不等于主题掌握。

切换主题时总结原主题证据，不把原题表现套用到新主题。上下文丢失且未成功读取记录时重新询问必要信息，不声称恢复了历史。成功读取时先展示摘要并等待继续/复习/更换目标选择。
用户要求导出时，可以提供可复制摘要；本地写入须有明确授权与位置，并经存储工具确认成功。当前会话变化不等于已保存进度。

未来复用边界：
- 教学规则：本 Skill 的教学流程与证据要求。
- 交互适配：未来课堂、教师对话、自由探索模式负责展示和输入，统一提交真实作答证据。
- 状态存储：当前支持单目标/单知识点本地读写、版本和冲突检查；尚无多用户或数据库。Phase 3 的可选复习与证据更新见 [最小复习](自适应复习.md)，不提供后台提醒。
- 网站：未来可以复用规则与字段语义，当前没有网站代码或可调用接口。

扩展时保留“已接触”和“已验证”的区别，并用跨模式一致性测试验证状态，不能仅增加模式名称就声称支持三模式。
