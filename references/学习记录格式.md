# V0.3 本地学习记录格式（v0.3.0-experimental.1）

存储基础现接入授权保存、摘要恢复与可选复习。以下是格式约定，不是真实学习记录。schema_version 保持为 1，未新增字段；旧的 Phase 1/2 合法记录仍可读取。授权操作见 [学习连续性](学习连续性.md)。

## 最小结构

| 字段 | 类型及用途 |
| --- | --- |
| schema_version | 整数 1，拒绝未知格式 |
| revision | 非负整数；新建草稿为 0，保存后递增，用于冲突检测 |
| learning_state.goal | 非空文本，当前学习目标 |
| learning_state.knowledge_point | 非空文本，一个知识点的范围 |
| learning_state.verification_status | unverified、immediate_passed、delayed_passed、needs_review |
| learning_evidence | 作答证据列表，允许空；跳过不创建证据 |
| adaptive_review.due_date | YYYY-MM-DD 或 null；日期按当前本机/用户当地日期解释，只有授权后才保存建议日期 |
| session_state.phase | intake、explain、await_answer、await_diagnosis、paused |
| session_state.pending_question | 非空文本或 null；等待作答/诊断时必须有问题 |
| session_state.resume_note | 必要接续说明或 null |

每条证据必须且仅包含 task_summary、response_summary、reasoning_summary、correctness、assistance、task_relation、occurred_at。
题目和答案摘要非空，理由允许 null；correctness 为 correct/partial/incorrect/unknown；assistance 为 independent/hinted/explained；task_relation 为 original/related/delayed；occurred_at 是带时区的 ISO 时间。

通过状态要求最近证据正确、独立且包含理由；delayed_passed 还要求 delayed 类型。delayed 需有之前的真实作答，且距最近作答至少24小时；related/delayed 不能与历史题目规范化文本相同，证据时间不得倒退。题意相关性与语义重复仍由教学规则和验收判断，工具不判断答案对错。单题通过不等于主题掌握。

## 读取与保存契约

使用 scripts/learning_store.py，Python 标准库，无网络与模型请求。路径必须由调用者明确提供，是仓库外、文件名为 learning-state.json 的绝对路径。

- read --path：不存在时成功返回 record=null；损坏、未知版本或无法读取时报错，不能当作无历史。
- save --path --expected-revision --confirmed：明确授权后从标准输入接收完整 JSON 草稿。未传 --confirmed 拒绝写入；它只是调用者对真实授权的确认标记，不能替代人工授权。草稿 revision 必须与 expected-revision 相同；新建必须为 0，已存在文件不能被新建操作覆盖。成功返回递增后的记录。
- resume --path：成功返回实际记录和恢复摘要；失败返回 unavailable 与具体原因，不生成历史。返回的选择需要由 Skill 展示并等待用户确认。
- 不接受额外字段；不保存完整聊天、账号信息或教材。调用者负责用户授权和必要摘要，工具不能识别所有私人信息。
- 同一文件只维护一个目标和知识点；更换范围须先保留旧记录，再选择另一目录。已有证据不能改写或删除。
- 独占锁覆盖读取、检查及替换过程。冲突必须重新读取；不自动删除他人或崩溃留下的锁。
- 临时文件写在目标目录，flush/fsync 完成后原子替换。替换前任何失败保留旧文件；不会先删除旧文件。

边界：适用于本地文件系统、使用同一工具的协作写入。不提供云盘/网络共享上的并发或断电恢复保证；用户或外部工具绕过锁修改文件不在保护范围内。崩溃可能留下 .lock 或 .tmp，确认没有写入进程后才可人工处理，禁止自动抢锁。

Phase 2 的 due_date=null 记录可直接恢复，不推测历史复习日程。Phase 3 使用 review-status、review-schedule、review-result、review-skip，详见 [复习规则](自适应复习.md)。字段和格式版本不变，只增加证据时间与不同题的校验。

## 本阶段验证

tests/学习连续性验证.py 使用虚构记录与仓库外临时目录。运行前通过 STUDY_TEST_TEMP 指定可写的临时目录。独立进程读写只是存储验证，不等于独立模型教学恢复、真实跨日或真人测试。
