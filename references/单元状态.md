# V0.6.4.1 单元阶段状态

只增加独立元数据，不修改知识点状态、原证据/教学/检测、保存工具、笔记、教材或DeepSeek接续。状态是流程位置，不是能力等级；completed表示本次检测流程完成，能力不足仍可待加强，用户仍能选择继续或复习。

使用 [状态工具](../scripts/unit_status.py)，沿用原库锁、修订校验、备份及安全替换。私人课程目录新增单元状态.json，按实际chapter_id隔离，每个单元保存unit_status、resume_status（仅暂停时保留之前阶段）、position_note和basis。外层kind=unit_status、schema_version=1、revision、course_id、units。原course.json、索引和learning-state.json结构不变。

## 状态及依据

- learning：正在学习，不凭访问目录判断完成。
- ready_for_test：用户确认本单元核心范围已学及必要练习已完成；列明实际learned_point_ids，工具检查属于当前单元且各有真实记录证据，不要求全独立通过或给分数。核心范围由实际目标确定，不能把点数量当比例门槛。未保存证据时只能在对话说明待核对，不擅自持久化“完成”。
- testing：用户实际选择开始检测；position_note写实际题号/位置，assessment_path有已保存检测记录时才填写，没有则null，不假称已保存题目。
- completed：已结束本次必要检测范围并确认完成，assessment_completed=true；assessment_path必须明确且记录可读、单元名匹配、有实际作答、无待回答问题。工具不按correctness/assistance/四维能力卡住完成，答错或提示后作答也能完成流程。减少检测范围须在原检测记录说明并取得确认，不能把未答题悄悄清空来制造完成。
- paused：用户选择暂停，保留原resume_status、依据与位置；提供新position_note时更新为当前实际暂停处，否则保留旧位置。resume操作恢复之前阶段，不默认回learning或重做检测。

只按真实学习和实际完成事件更新，无分数、排名、强制完成或自动跳章。入口跳过检测不写状态；已有ready_for_test仍保持，用户主动要求保存暂停时才写paused。completed不是“完全掌握”，不足另列四维观察，不改原知识点验证状态。

## 写入与恢复

先read/continue取得实际course_id、chapter_id、index_revision及unit_status_revision。写入要用户授权，set --root <明确私人库> --course-id <编号> --chapter-id <编号> --status <阶段或resume> --expected-index-revision <实际值> --expected-revision <状态文件修订号，新文件0> --confirmed。

标准输入只有basis与position_note。basis只有learned_point_ids数组、required_exercises_completed布尔、assessment_path明确路径或null、assessment_completed布尔。布尔表示核对后的流程事实，不是用户能力判断。assessment_path仅读取用户指定记录，不搜索；程序仅校验单元名和记录基本完成条件，Agent还须核对其实际课程和本次检测范围，不能错用另一课程同名章节记录。

只写单元状态.json，不更新原索引导航、知识点证据、检测记录、笔记或日期。写入失败保留旧状态；未知版本/损坏停止，不重建空文件。原记录在两次读取间发生变化时，应重新核对实际事实，本层不承诺跨多文件事务或自动推断教学语义。

“继续学习”优先unit_status.py continue --root <原明确私人目录>，它调用原只读入口并叠加unit_states、current_unit_state、unit_status_revision；不改原摘要或自动写状态。缺少侧文件显示默认learning且saved=false，明确“尚未保存单元状态”，不能冒称恢复了历史。状态损坏单独提示，原知识点仍可恢复。无当前知识点时展示单元列表等待选择，不猜当前章节。

恢复先显示单元阶段及原未答题/位置，等待用户选择。ready_for_test可提供原可选检测入口；testing/paused仍需按原检测约定提供明确检测记录路径，只有position_note不能恢复完整题目。completed可进入下一单元，但先保留具体待加强/待验证能力并等待选择；不自动修改导航。

单元报告将流程阶段与能力分别展示：当前状态“已完成检测”，下方可同时列概念理解已验证、专业表达待加强、应用已验证、迁移待验证。报告生成和状态更新都不产生新学习证据。中英文同样处理，DeepSeek独立指令未更新。
