# V0.3 Experimental 真实使用指南

这是个人试用指南，不是学习效果承诺。你只需正常回答，不用编辑 JSON 文件。

## 安装

使用支持 Agent Skills 的 Agent，将完整 ai-study-mentor-skill 文件夹放入该客户端支持的技能目录，保留 SKILL.md、references/、scripts/。目录与调用方式以客户端说明为准；其他 Agent 尚未逐一验证。对话教学不需要 Python，本地保存与恢复需要 Python 3.10 以上及文件读写权限。

Codex 示例：用户技能目录可使用 ~/.agents/skills；部分客户端也识别 ~/.codex/skills。只保留一个有效同名安装。新建聊天，输入 $ai-study-mentor-skill 并选择候选项。若没有出现，重启客户端并检查文件夹层级。官方说明：https://learn.chatgpt.com/docs/build-skills 。

请从 v0.3.0-experimental.1 Pre-release 下载完整源码包。GitHub 的 v0.1.3 没有这些 V0.3 连续性能力，不要用稳定版下载替代本次试用版本。

## 第一次开始

新建学习聊天，选择该技能后发送：

> 使用 $ai-study-mentor-skill 带我学购物折扣。请先了解我的目标和基础。今天结束时请问我要不要保存进度。

回答它的目标和基础问题，尝试练习并说说理由。不懂就说“不懂，请更简单”；需要提示就直接问。不要为了测试而假装会做。

## 开启保存

结束时说“今天先到这里”。如果没有询问保存，你可以说“请保存我的学习进度”。

AI 应先解释保存目标、知识点、状态、题目和作答必要摘要、提示情况、下一步与有证据时的复习建议；不保存完整聊天或教材。保存位置由你选择，文件名必须是 learning-state.json，放在 Skill 仓库之外。

了解范围后告诉 AI：“我同意保存这些必要摘要，位置是【你选择的完整文件路径】。请确认实际保存成功，并告诉我下次恢复需要的路径。”将括号内容替换为实际路径，不必自己创建或编辑 JSON。只给路径不等于授权。

保留它返回的路径。若保存失败，不要当作成功；请它解释原因并保留当前摘要。没有实际作答也可保存暂停位置，但不能产生虚构证据或复习日期。

## 第二天恢复

新建独立聊天，不复制旧聊天，选择该技能并发送：

> 使用 $ai-study-mentor-skill，恢复我的学习记录。

它应询问位置。粘贴你保存的完整路径；看到上次目标、状态、未完成题和下一步摘要后，确认“继续学习”或“先复习”。发现摘要不对先纠正，别继续。

复习应使用不同但相关的新题，不提前给答案。距最近实际作答至少24小时才算延迟复测；仅仅到了第二天不一定够。需要保存本次结果时重新授权同一文件。独立答对、提示后答对、答错和跳过应分别记录，不能都叫掌握。

## 常见问题

- 没看到技能：检查安装位置、文件夹层级，尝试新聊天或重启。普通 AI 回答不能证明已加载；可请它说明实际读取的 Skill 版本和文件。
- 说找不到记录：检查你给出的完整路径，不让它搜索全部私人文件或编造历史。
- 文件损坏或冲突：保留原文件，不强制覆盖，让 AI 说明错误；必要时另选位置。
- 想换知识点：使用另一个目录中的 learning-state.json，当前格式只支持一个目标和知识点。
- 跳过练习：可以跳过，状态应保留未验证，不会强制复习。
- 能自动提醒吗：不能，复习建议只在你主动使用时检查。
- 隐私安全吗：这是本地文件，不加密；摘要仍可能包含个人信息，不要填写隐私或上传公开仓库。Agent 服务本身的数据政策另行适用。

使用后可参考 [个人真实使用记录模板](../tests/个人真实使用记录模板.md)，把填写后的副本保存在私人目录，不提交仓库。
