# V0.3 Phase 3 验收（开发评审，未发布）

日期：2026-10-12。范围仅为可选复习入口、不同相关题、时间资格、提示程度、证据追加与状态更新。没有画像、方法推荐、后台提醒、数据库、多用户或网站。

## 自动测试

新增12项复习检查：到期入口、提前复习不算延迟、延迟独立通过、提示后不算通过、错误触发重新诊断、跳过不改变文件、重复题拒绝、伪造短间隔延迟记录拒绝、授权与修订冲突、到期但不足24小时、复测写入失败保护、复测CLI完整调用。连同先前23项共35项，最终35/35通过。项目7/7检查、官方quick_validate和差异格式检查通过。

复习间隔采用实验规则：实际作答后可建议次日检查；新题距最近作答至少24小时才符合 delayed；延迟独立通过建议3天后，其他复测结果建议次日。规则透明但未验证学习效果。工具只检查相同文本的规范化重复，不能自动证明语义新颖性、题意相关性或答案正确。

## 模型测试计划

使用当前配置模型与现有登录。每个案例分别进行首次教学、作答、授权保存、独立新会话恢复、选择复习与新题、作答和状态保存。恢复提示只提供 Skill、记录路径与明确标注的模拟时钟，不包含旧聊天。原始事件及测试学习文件保存在仓库外。

- 数学：首次为原价50元、八折，独立作答40元及理由；恢复后换外套300元、七折，独立作答210元及理由。检查新旧题不同、delayed/independent、delayed_passed 和历史保留。
- Python：首次把 colors[1] 当作首项，经过错因纠正后做 nums=[8,3,6]、nums[2]；恢复后换 letters=["K","M","P","Q"]、letters[1]，故意回答K并说明从1开始。检查错误证据、needs_review、V0.2 诊断与历史正确证据保留。

时间测试将各案例最近首次作答后的两天作为 --test-now，明确属于模拟时钟，不能记为真实跨日。开发代理扮演学习者，没有真人学习数据。

两组均由新会话实际调用 resume 读取指定文件，展示恢复摘要及先复习/继续学习/更换目标，等待选择；用户主动选复习并授权本次写入后才生成新题、记录结果。会话标识经核对不同，恢复没有接收旧聊天，也没有读取首次会话目录或原始日志。

两个结果均实际调用 review-result，保存后修订号为3。原有正确证据与时间保持不变；数学只认当前知识点的新检查通过，不宣称全主题掌握。Python 新会话实际读取 V0.2 错因诊断参考，针对索引与位置混淆解释，并提出 pets=["猫","狗","兔"]、pets[0] 的新检查，等待回答，未虚构后续答案。此后续检查题尚未保存等待位置；若要在该处暂停，需按授权保存流程保存新位置。

新旧题由开发代理作语义核对，实际数据/代码不同，复习出题回合没有展示答案。题目参数与学习者回答由测试脚本预先指定，因此是集成验收，不是开放题目生成质量或学习增益研究。提示后正确与跳过本轮只由自动测试覆盖，没有分别运行模型对话。

所有延迟状态都基于明确的两天模拟时钟；原始记录时间未被改写。没有真实跨日或真人学习证据，原始日志、会话标识和虚构学习文件只留在仓库外。模型评分与错因解释的语义正确性不能由存储工具保证，评审也不是独立盲评。
