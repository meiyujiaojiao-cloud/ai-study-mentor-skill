# V0.1.3 桌面教学验收记录

整理日期：2026-10-12。证据来源：维护者实际操作 Codex 桌面应用后，在开发聊天中逐轮回传的技能候选确认及导师回复。
开发代理未直接观察桌面或获得完整原始工具日志。桌面客户端版本与模型未记录，不沿用 CLI 测试的版本或模型信息。
本文件只保留虚构购物题的功能验收摘要，没有账号、机器路径、真实个人学习进度或完整私人聊天。

## 测试范围与结果
| 项目 | 实际观察 | 结果 |
| --- | --- | --- |
| 技能发现 | 新聊天输入技能名称后，维护者确认同名候选出现 | 通过 |
| 显式调用 | 按指导选择 ai-study-mentor-skill，随后收到教学回复 | 通过（维护者操作回传证据，非独立工具审计） |
| 首轮诊断 | 全新聊天询问学习目标，以及分数、小数和50%的基础理解；未提前给掌握结论 | 通过 |
| A 正常教学 | 收到基础后短讲百分比与折扣、给例子和一道题并等待；此前200元七五折的150元正确答案获本题通过与下一步建议 | 通过；诊断与正确作答证据来自不同测试片段，未证明同一次冷启动完整A |
| B 错误反馈与复测 | 200元七折故意答60元并写200×0.3；导师指出算出的是省的钱，正确支付比例70%，另出300元六折题；180元与理由正确后确认本题通过 | 通过 |
| C 降低难度 | 表示听不懂后，停止小数乘法，换成10元五折付一半，询问平均分两份的单步问题 | 通过；未完成该简单题，不宣称掌握 |
| D 偏题与返回 | 回答天空颜色问题，保留10元分两份停点；要求返回后准确续接原问题，不编造作答 | 通过 |
| E 跳过练习 | 同意跳过，简讲五折=50%=一半，不强迫出题；追问是否掌握时明确已讲解未验证 | 通过 |

一次早期操作仍在原聊天中续学，未满足新会话条件；改为真正空白聊天后重新验证了首轮诊断。这是测试操作纠正，不计作新会话功能已经失败或已经通过的证据。
B–E 是同一桌面聊天连续验证，不是相互隔离的新会话；与 [CLI验收记录](真实教学验收记录.md) 的分叉测试互补。

## 剩余限制
- 未测隐式触发与普通问答误触发；本版以显式选择技能作为推荐入口。
- 未测所有主题、所有模型、所有操作系统或多名独立使用者。
- 没有桌面完整工具日志；不把手动回传等同于独立重放。
- 不是真人学习效果研究，不证明长期保持或迁移能力。
- 不存在跨会话学习保存、教材解析、完整课程或网站实现。
- 本轮仅核对并记录既有对话，不重新运行模型或调用付费API。
