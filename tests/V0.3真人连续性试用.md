# V0.3 真人连续性试用准备（3人，尚未执行）

本方案只测试保存和恢复是否易懂、连续学习是否有价值、是否遇到保存障碍。不比较成绩，不评估智力、学习类型或长期学习效果。

## 参与与隐私

邀请3名自愿用户，使用U1/U2/U3代号，不收真实姓名、账号、教材或完整聊天。每人使用自己的Codex环境和自己的仓库外学习文件；这不是多用户系统开发。说明这是实验版，随时可退出、跳过题目或删除自己的记录。

使用一个公开常识小主题，例如购物折扣或Python列表索引，不使用私人教材。学习记录只保存在本人选择的位置；试用报告只记匿名观察与经同意的短评。不要回传密码、密钥、未脱敏截图或带个人目录的完整记录。

## 最小流程

首次约10分钟：

1. 维护者先准备技术检查通过的V0.3评审候选与独立测试环境，确认实际加载的是V0.3文件而非已安装的v0.1.3。提供完整文件夹与 [安装说明](../docs/新手安装与测试指南.md)，观察能否选择Skill。若安装需协助，单独记录，不冒充独立完成；不要覆盖原有稳定安装。
2. 用户自行选择一个小知识点，学习并尝试一道题。答对与否不是试用是否成功的标准。
3. 请用户说“保存我的学习进度”。观察是否理解保存的数据、是否知道位置由自己选择、是否知道需要确认。让用户自行选仓库外位置并保存。
4. 请用户用自己的话说下次如何找回记录；不要求记住技术命令。

第二次约10分钟，建议至少24小时后：

1. 新建Codex聊天，选择相同Skill；不复制旧聊天，只提供“继续上次学习”和自己的文件位置。
2. 观察是否理解恢复摘要与“先复习/继续学习/更换目标”；允许自由选择，不强制答题。
3. 愿意复习者尝试不同相关题。访谈只问新题是否帮助判断自己还记得什么，不计算成绩变化。
4. 结束时确认记录是否成功保存，以及用户是否知道怎样停止保存或删除自己的文件。

若不足24小时也可观察操作可用性，但标记“提前复习”，不能算真实延迟复测。

## 访谈问题

- 你认为保存了什么？它在哪里？
- 下次怎样继续？哪里让你不确定？
- 恢复摘要是否让你知道自己停在哪里？
- 换一道题检查是否有帮助？为什么？可回答“没有帮助”。
- 是否遇到找不到文件、权限、Python环境、格式错误或保存失败？提示是否让你知道怎么继续？
- 是否清楚可以跳过复习、不保存或更换目标？
