# V0.2 错因诊断对照报告（开发评审，未发布）

整理日期：2026-10-12。

## 实验定位与问题

AI Study Mentor 是一个实验性的自适应学习框架，以 Codex Skill 规则组织诊断、解释、练习与反馈。V0.2 探索的是：根据有限的作答证据选择教学策略，是否比直接解释更合适。

普通 AI 也能解释错误和调整教学，本报告不将这些能力描述为 Skill 独有。问题在于，一次问答可能不足以确定用户为什么错、真实理解到哪一步，或当前讲解是否适合；如果缺少诊断与复测，后续解释可能没有针对实际障碍调整。

本轮尝试四个环节：依据证据进行错因分类；选择针对性解释；用不同但相关的题目复测；根据后续反馈更新错因假设和教学方式。原因不明时允许先问一个诊断问题，不根据单次错误判断学习者能力。

**V0.2 目前只有模拟案例验证，没有真人学习数据。** 本实验评估模型回复中的诊断与策略设计，不测量真实学习者是否学会、保持或迁移了知识。历史版本的桌面操作验收也不能替代 V0.2 的真人学习效果研究。

## 结论

**已实现错因诊断规则；本轮没有达到预先设定的“明显改善”门槛。**
V0.2在留出集为10.00，较普通Codex的8.50提高1.50，但较v0.1.3的9.50只提高0.50，未达到对两个基线均至少提高1分的门槛。不能宣称V0.2已明显优于旧版，更不能推论长期学习效果。

## 预注册与公平性

12个虚构案例在首个请求前固定，数学与Python各6个，覆盖概念、题意、计算、前置、推理与证据/未知。8个开发案例，4个留出案例M03/M06/P02/P05。标准和案例在本地提交7edd844先行保存；规则定稿指纹在评阅留出输出之前保存。本轮未根据留出输出继续改教学规则。
留出是“未评阅输出”，不是独立盲测：同一开发代理编写了全部案例，也参与实现和评分，可能有选择与评审偏差。每例每组一次，不作统计显著性声明。

三个条件均使用Codex CLI 0.160.0、当前配置gpt-6-astra、low和现有ChatGPT登录。没有切换模型、购买额度或调用另购API。两个并行CLI请求仅是批量测试执行，不是多Agent教学架构。
普通条件实际skills/list为零启用Skill，12例没有执行工具；两个Skill条件显式读取独立项目中的正确SKILL.md/参考文件。v0.1.3快照来自已公开版本提交ac5601a，不是可变main；V0.2使用单独冻结副本。各例新会话，不向模型发送评分答案，不允许读tests，检查未见基准答案文件读取。

## 观察

- 普通Codex已经能指出多类错误、保留正确步骤，并在不同题目中给出相关解释；不能把普通模型描绘成只会统一重讲。
- v0.1.3的开发案例已经全部达到本轮量表上限，量表与案例存在明显天花板效应；V0.2全满分不能理解为现实中没有失败或普遍完美。
- 主要可观察增益在M06：仅答x=8且没步骤时，普通/旧版承认未知但立即教减法/移项；V0.2先问怎样得到8。得到看成x−1=7的解释后，三组都能更新为误读。V0.2改进的是提前选择诊断步骤，并非旧版无法更新诊断。
- 普通条件部分检查复用了刚讲过、已给答案的例子；旧版与V0.2更多采用新题。这一优势主要属于已有Skill规则，而不是本轮新增能力。
- M06与P06的6个固定后续回合均完成：根据新解释更新原因/证据，不将单题或单个切片正确扩称全部掌握。后续回合不纳入12例均分，学习者解释是预设的，不是实际学习产生的证据。

## 复现说明

需要已有Codex CLI登录与可用额度，Python标准库即可。使用全新的仓库外输出目录，保存原始结果；不要提交其JSONL/日志/会话信息。运行脚本不会购买服务、改变用户配置或自动评分。

1. 从公开v0.1.3标签取完整冻结文件夹；不要用main替代旧版。保留对应版本指纹。
2. 在输出目录建立workspaces/ordinary、workspaces/v013、workspaces/v02。两个Skill版本分别复制到各自的 .agents/skills/ai-study-mentor-skill。V0.2副本只需SKILL.md、references、examples和原有人工教学说明，**不要复制V0.2案例/评分答案/结果到模型工作区**。
3. 在三个工作区初始化本地Git，以支持项目技能发现。第一次运行用ordinary/v013，完成开发集评阅后冻结规则，再运行v02；4个留出输出等规则固定后才评阅。
4. 运行以下命令，替换仓库外相对输出目录；脚本默认查询实际skills/list，生成并验证进程专用禁用覆盖，不改用户配置。技能条件的项目Skill保持可读、由用户显式调用。

```sh
python tests/运行对照测试.py --output ../对照原始结果 --conditions ordinary v013 --split all
python tests/运行对照测试.py --output ../对照原始结果 --conditions v02 --split all
```

复用已有结果文件会拒绝覆盖，重新实验须用新输出目录并保留原结果。脚本中的快照安装和评分是显式人工步骤，不能据命令退出0就宣称教学通过。自己复现时模型环境可能不同，应记录实际配置并在三组保持一致。本轮原始执行器在结束后补齐了可移植的技能隔离入口与防覆盖检查；模型执行过程使用原先已验证的显式禁用配置，两者不改变本轮输出。
